# Digital Clock Documentation

## Features
- Displays current time in different formats.
- Supports multiple pre-configured time zones.
- Allows users to customize time zone settings.
- Provides alarm and timer functionalities.

## Pre-configured Time Zones
- UTC
- GMT
- PST (Pacific Standard Time)
- EST (Eastern Standard Time)
- CST (Central Standard Time)
